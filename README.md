# World Explorer 
Ita an app that is build with vite.

## Prerequisites
You have to have [Node.js] installed on your computer.

## How to start the application (Development)
1. Open your terminal and navigate to the root of the project folder.
2. Install the required dependencies by running:
   ```bash
   npm install
   ```
3. Start the development server by running:
   ```bash
   npm run dev
   ```
4. Open your web browser and navigate to the local URL provided in the terminal.
